Rental FAQs

Can one machine run both 5-inch and 6-inch gutters?

Some machines are configured for both sizes. Specify both sizes in your request and confirm the exact machine configuration before arranging the rental.

What should I confirm before bringing my own coil?

Confirm the material, width, thickness and maximum coil weight the machine supports.

Does downloading a request reserve a machine?

A downloaded request is a project brief. Confirm availability, rates, included equipment and pickup or delivery directly with your provider.
